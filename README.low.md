# Headroom — LOW

The model doesn't get tired. You do.

```text
🧠 22% · Human: LOW · BREAK
```

**Recommendation:** install it and try a break.

- **Human Effort.** Set LOW, MEDIUM, or HIGH. Answers get shorter or longer. The score stays put.
- **Headroom score.** A 0–100 estimate of session pressure. It is not a medical reading.
- **Break & Delegate.** Below 35, it asks about a 7-minute break. A new chat checks for safe work, does at most three steps, or does nothing.

**Risk:** the break limits are instructions to the agent, not a sandbox.

Install `artem.headroom` from [Open VSX](https://open-vsx.org/extension/artem/headroom).
